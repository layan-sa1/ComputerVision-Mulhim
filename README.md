# نسخة جاهزة لـ Expo Snack

خطوات التجربة:
1. روحي https://snack.expo.dev
2. احذفي محتوى App.js الافتراضي، والصقي محتوى App.js من هذا المجلد
3. سوّي ملف جديد بنفس المسار المكتوب بأعلى كل ملف (زر "+" بقائمة الملفات يسار الشاشة)
   لازم تضيفي أيضًا: ExercisesData.js
4. **مهم — رفع الصور:** بالسنارك اضغطي "+" ثم بوّبي "Assets" وارفعي كل صور مجلد assets
   بهذا المشروع بنفس الاسم بالضبط (عشان تتطابق مع require بالكود):
   - squat.png
   - medball-pushup.png
   - incline-press.png
   - incline-press-close-grip.png
   - incline-press-rotation.png
   - incline-flye.png
   - mascot-flame.png
5. ثبّتي Expo Go بجوالك وامسحي QR Code اللي يطلع
